# Toy Project
## 금융 데이터 기반 데이터 플랫폼 구축 프로젝트

### 프로젝트 개요
- 금융위원회 OpenAPI를 활용하여 아래의 데이터를 수집한다.
  1. **기업기본정보**
  2. **기업재무정보**
  3. **주식시세정보**
  4. **주식배당정보**
  5. **주식발행정보**

- 데이터 파이프라인(실시간 또는 배치성)을 구축한다.

- 분석 결과를 대시보드 화면에서 시각화한다.

- 생성형 AI를 기반으로 한 로보어드바이저 기능을 제공한다.

### 사용 스킬
- Python (필요 시, FastAPI 활용 예정)
- PostgreSQL
- Airflow / Kafka
- Grafana / Prometheus
- Docker
- AWS (단, 경우에 따라 클라우드가 아닌 로컬 환경에서 구축할 수도 있음)
